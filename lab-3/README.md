# Лабораторна робота 3 - Sequence-діаграми

**Дисципліна:** Компоненти програмної інженерії

## Опис роботи

У цій лабораторній роботі я створив 4 sequence-діаграми для UC-2 "Оплата та підтвердження замовлення" із другої лабораторної.

Діаграми показують, як система бронювання квитків у кінотеатр обробляє успішну оплату, помилку платежу, завершення часу оплати та запізніле підтвердження від платіжного шлюзу.

## Файли лабораторної

- [spec.md](spec.md) — опис сценаріїв та критеріїв прийняття.
- [Код діаграм](diagrams/code/) — Mermaid-код чотирьох sequence-діаграм.
- [PNG діаграм](diagrams/png/) — зображення готових діаграм.
- [ai_prompts.md](ai_prompts.md) — запити до AI та його відповіді.
- [ADR](adr/0001-order-cancellation.md) — рішення щодо перевірки статусу перед скасуванням замовлення.
- [DEFENSE.md](DEFENSE.md) — підсумок роботи, знайдені помилки та їх виправлення.

## Використання AI

Для створення та перевірки sequence-діаграм я використовував **GitHub Copilot** у VS Code. За його допомогою були створені початкові діаграми, знайдені недоліки та внесені виправлення відповідно до уточнень у специфікації.

**ChatGPT** використовувався як допоміжний інструмент для переформулювання деяких текстів, пояснення технічних моментів та допомоги з оформленням документації.

Усі запити й відповіді Copilot, пов'язані зі створенням та виправленням діаграм, збережені у файлі `ai_prompts.md`.
