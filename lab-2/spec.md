Я роблю Лабораторну роботу 2 з предмета "Аналіз систем" (тема: Вимоги та Use Cases).

Предметна область — система онлайн-бронювання квитків у кіно

Моя база даних з Лаб 1 складається з 6 таблиць: CLIENT, HALL, SEAT, MOVIE, ORDER, PAYMENT.

Напиши для цієї системи:
1. Список акторів (люди + зовнішній платіжний сервіс).
2. EARS-вимоги (використай формати: WHEN ..., system SHALL ...; WHILE ...; IF ... THEN ...). Додай мінімум 6-7 вимог.
3. Дві User Stories (одна для Клієнта, одна для Адміна) і до них 2-3 Gherkin-сценарії (Given/When/Then).
